## Ghi chú thời lượng

Tổng ~1.375 âm tiết. Ở rate +5% (≈3,9–4,1 âm tiết/giây theo số đo dự án trước) phần lời ≈ 5:40; cộng ~50s nghỉ chuyển cảnh, 4s chờ quiz, thời gian quan sát sơ đồ → **ước lượng 6:20–7:00**. Nếu đo mẫu thấy chậm/nhanh hơn, điều chỉnh rate hoặc khoảng nghỉ có chủ đích (không tăng tốc để ép thời lượng — mục 4.4). Tiêu đề cảnh ghi mốc thời gian là dự kiến, sẽ chốt lại theo audio thật.

## Phân loại công nghệ đã rà (không nhầm lẫn)

- Node.js = **runtime** JavaScript; Express = framework Node.js; React = **thư viện** UI (không gọi framework); Laravel = framework PHP; Spring Boot = framework Java; MySQL/PostgreSQL = hệ quản trị CSDL; Figma/Jira/Postman/Docker/VS Code = công cụ; Git = hệ thống quản lý phiên bản, GitHub = nền tảng lưu trữ.
- Ví dụ đăng nhập chỉ mô tả luồng, không hiển thị mật khẩu thật; không có số liệu/benchmark bịa.
- Mô hình 4 nhóm và 6 giai đoạn trình bày là **mô hình tham khảo** (đúng lưu ý mục 3.1 bản gốc).
